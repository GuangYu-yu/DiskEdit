# 03 行为基线

基线 = 仓库根目录现有实现的对外行为。**源码是唯一事实来源，本文只记录读数。** T0 逐项从源码读取；本文与源码不一致时按源码更新本文并登记差异，本文不得成为覆盖源码的第二来源。

本文是人工摘要，可能漏项。机器普查的冻结结果（`baseline/census.json`、`baseline/refusal-sites.tsv`）与本文不一致时，以冻结结果为准，并回头补本文。

## 2. 退出码

七值，判定顺序即下表顺序，命中即停：

| 码 | 含义 |
| --- | --- |
| `2` | 用法与解析错误：未知命令、未声明选项、缺参数、缺 `--yes`、值域非法、组合非法；不需探测即可判定 |
| `1` | 写目标字节前的不变量破坏或内部错误 |
| `6` | 能力不支持：所需能力为不支持或设计限制；运行期探测失败（工具缺失、扇区无法构造几何、身份不可证明） |
| `5` | 本次已写目标字节或写事实不可判定；记录待恢复；持久状态已达成但内核视图未同步；目标可能已改变 |
| `4` | 已进入执行、目标字节未变的 I/O 或环境故障 |
| `3` | 请求被拒、记录损坏、证据指向外来或损坏、扫描超限、检查器退出非零 |
| `0` | 成功：未写目标且未建记录，或记录已清理且视图已同步，或完整回滚并归档 |

要点：

- 证据类命中优先于"准入拒绝"：同一落点既有挂载又有未完成记录时落 `5`，不改判 `3`。
- `5` 的输出必须含三样：目标可能已改变、证据路径、下一步命令（`inspect` / `recover` / 放弃回滚 之一）。不得只写"请重试"。
- `3` 的输出不含证据路径与恢复动作。
- 退出码只在一处产生；任何调用点不得自行选码。

## 3. 机器可读输出

- 基线实际：`info` 与 `records *` 恒输出 JSON；`inspect`、`check` 输出人读文本；不存在 `--json` 选项。
- 字段名、类型与取值语义的基线读数存 `plan/baseline/json/`；本实现按 D9 输出自己的结构化字段集，不复刻基线字段名与文本。
- 人读文本不作契约，除非 T0 列为"判定行"（例如退出码语义那一行、恢复三要素）。判定行清单存 `plan/baseline/judgment-lines.md`。

## 4. 文件系统矩阵

识别 15 类：`squashfs`、`erofs`、`ext`、`xfs`、`btrfs`、`f2fs`、`exfat`、`vfat`、`ntfs`、`hfsplus`、`apfs`、`bcachefs`、`jfs`、`reiserfs`、`udf`；另有 `swap` 签名与"未知"。

可操作 7 族。下表由 T0 从能力表逐格读出并冻结，不支持项写明原因（不支持 / 设计限制）。已冻结结论的源码位置见 `baseline/capability-matrix.md`；本表不得再出现"待确认"。

| 族 | 扩容 | 收缩 | 属性 | 检查 | 建卷 |
| --- | --- | --- | --- | --- | --- |
| ext | 是 | 是 | 是 | 是 | 是 |
| xfs | 是（需挂载） | 否（设计限制：不支持收缩） | 是 | 是 | 是 |
| btrfs | 是 | 单设备可收缩；多设备否（设计限制） | 是 | 是 | 是 |
| f2fs | 是 | 否（设计限制：未接线） | 否（设计限制：未接线） | 是 | 是 |
| ntfs | 是 | 是 | 是 | 是 | 是 |
| vfat | 是 | 否（设计限制：未接线） | 是 | 是 | 是 |
| exfat | 否（设计限制：未接线） | 否（设计限制：未接线） | 是 | 是 | 是 |
| swap | 否（不支持原地扩容） | 否（不支持原地收缩） | 是 | 否（不支持） | 是 |

能力口径：`设计支持（未实测）` 与 `不适用` 视为满足；`不支持` 与 `设计限制` 落 `6`。探测通过只证明工具链可用，不承诺掉电持久。

## 5. 必须复现的行为约束

每条都以"运行基线二进制可观察到"为准；T0 逐条确认。

| # | 约束 |
| --- | --- |
| B1 | 扇区集合 `{512, 1024, 2048, 4096, 8192, 16384, 32768, 65536}`；入参在集合外落 `2`；内核报告集合外值（如 520/524/528）按无法构造几何落 `6`；表内 LBA 按表扇区解释，容器扇区只用于整盘字节量换算 |
| B2 | 身份等级 `Strong`：WWN/EUI、多次读数一致的 serial、loop backing 的文件标识、镜像的文件标识；其余（dm、md、仅 major:minor、读数不一致）为不可用，写命令落 `6` |
| B3 | 锁键按载体派生：块设备取整盘稳定身份，分区号不进锁键；镜像取文件对象；loop 取 backing 文件对象。记录目录按目标身份派生。二者分离，同一整盘与其分区共用一把锁 |
| B4 | 占用作用域：整盘 = 自身与全部分区；分区 = 父盘与父盘全部分区；dm/md = 自身。五条证据：挂载表、交换区表、`holders/`（递归不超过 8 层）、阵列成员、镜像对应 loop 的 backing 标识。五条证据任一来源存在但不可读、不可解析、权限不足，一律按已占用。“系统没有该子系统”只能由独立信号证明（如 `/proc` 挂载点缺失且 `mountinfo` 不可得）；证明不了即按已占用。多设备 btrfs 成员见 B17。只读命令不受约束 |
| B5 | 证据路径父链逐级 `O_NOFOLLOW\|O_DIRECTORY` 或 `openat2` 加 `RESOLVE_NO_SYMLINKS`；目录 `0700`、记录文件 `0600`；末级为符号链接或硬链接数大于 1 时拒绝；临时名 `.<正式名>.<pid>.<随机>.tmp`，`O_CREAT\|O_EXCL` |
| B6 | 原像只覆盖表区；搬移类操作已写的数据不回滚、不回收、旧位置不清零 |
| B7 | 回滚准入六条同时成立：持有独占锁、锁内重探身份相符、记录完整且原像非空、`--yes` 已满足、盘面按原像逐条核对相符、外部工具段未启动。进程号、时间戳、路径都不构成资格 |
| B8 | 放弃回滚只看对象与归属，不看载荷完好；持锁校验后同目录建 `.abandoned` 链接，目录 `fsync`；命名冲突按现有最大编号顺延，不覆盖；该动作不改目标字节 |
| B9 | 准入顺序固定：探测锁键 → 取目标锁 → 锁内重探身份 → 查记录 → 探测占用 → 判定。不跳步、不并行、不先写后补 |
| B10 | `new` 覆盖门：`would_overwrite = 非全零 或 已识别分区表`；为真且未给覆盖旗标落 `3`；写前重读首、第二、末三个扇区比对摘要，不等则不写 |
| B11 | `new` 最小容量：GPT 需 `total_lba ≥ 2E + 4`，`E = ceil(16384 / sector_size)`；MBR 需 `total_lba ≥ 3` 且可用区非空 |
| B12 | GPT 表步的写入区间一次列全四段：主头（含 CRC）、主项数组、备份项数组、备份头（含 CRC）；`new` 另把保护性 MBR 列入同一份区间。只写一侧副本即该步未完成 |
| B13 | 分区收缩准入：文件系统已先缩到目标大小，且新终点不早于文件系统末端；否则落 `3`，不写表、不调工具 |
| B14 | 搬移允许与本分区原区间相交：位移为正时尾→头、为负时头→尾；单块字节数取 `min(--chunk, abs(位移) × 扇区)`；自重叠时每块落盘后立即写检查点 |
| B15 | 建卷工具与参数按族固定：ext2/3/4 用 `mke2fs -t`；xfs、btrfs、f2fs 带 `-f`；标签旗标按族取 `-L` / `-l` / `-n`；建卷前按固定区间擦残留签名，屏障先于第一次擦除落盘；LVM PV 不建卷，直接拒绝并指路 |
| B16 | 表写入按段推进：每段覆盖前先把该段整扇区原像登记并落盘，成功后才写；整步写完并校验通过后才提交进度。工具步骤在进程创建前与退出后各落一次盘；搬移按块累计推进 |
| B17 | 多设备 btrfs 成员：目标是一块成员盘时，即使未挂载、不在 holders 与 loops 里，也按已占用。依据是 superblock 的成员证据，不得只查挂载表 |
| B18 | GPT 观测按候选扇区尺寸逐个尝试：容器报告的尺寸、512、4096；主头、主项数组、备份头、备份项数组都要在命中的口径下读。按容器尺寸读不到不得判为表不可用（旧 `src/table/gpt_parse.rs:597-607`） |
| B19 | 扇区尺寸在打开目标时即过允许集合（512 起、2 的幂、不超过 65536），不论来自入参还是内核回报；集合外按无法构造几何落 `6`（旧 `src/dev/source.rs:556-560`、`src/domain.rs:37-48`） |
| B20 | 写入前在目标侧重算上界：偏移加长度用 checked 运算，结果大于目标此刻长度即拒绝；镜像再读一次此刻的文件长度。普通文件不得被写通道静默扩展（旧 `src/dev/source.rs:1067-1094`） |
| B21 | 搬移与复制的源、目标区间部分重叠时：目标在前则尾到头，源在前则头到尾；区间关系判不出则拒绝。续跑凭持久记录里的块游标、已写前缀摘要、创建时几何快照，三者缺一不续跑，只能从头重放 |
| B22 | `recover`、表区回放、回滚一律不豁免占用闸与准入顺序（B9 全序）：目标被挂载、在用 swap、阵列成员、holder 持有时拒绝 |
| B23 | 记录的清理与放弃：解码记录、比对载体身份、排除外来布局、排除外来条目，四道闸都过才允许改名归档或删除；删除前回读并重新匹配，删除后对目录 `fsync`。任一闸不过则整体拒绝并保留原记录（旧 `src/cmd/release.rs:197-204, 282-327`） |
| B24 | 回滚写前逐条读目标当前字节并与原像核对（B7 第五条）。外部改动、撕裂、双断点一律拒绝，不得覆盖 |
| B25 | 保护 MBR：槽 2 到 4 必须全零；`SizeInLBA` 分三态 `Normal`、`NeedsRepair{Stale, Compat512}`、`Inconsistent`；`Inconsistent` 时拒绝自动修复；已合规的保护 MBR 不重写（旧 `src/table/mbr.rs:440-444`、`src/table/gpt_parse.rs:111-130, 576-595`、`src/gpt_policy.rs:94-99`、`src/table/gpt_write.rs:229-258`） |
| B26 | 对齐：`--align` 缺省为不对齐；显式 LBA 原样落位；`--start align` 以分区当前起点为锚取下一个 1 MiB 边界；`resize --end` 的末端按 `--align` 下取整（旧 `src/cli.rs:1405`、`src/cmd/layout.rs:479, 1393-1400`、`src/support.rs:416-431`） |
| B27 | 外部步骤（工具、跨进程）超时或回报不可得时，结果记为不确定，按已写目标处理：退出码 `5`、记录待恢复；不得重试，不得报未改动 |

## 6. 在线扩缩与 LVM

在线（目标已挂载或在用）必须复现：

- 先写盘上分区表，再让内核重读；重读用 `partx -u`，失败时以 `BLKPG` 兜底。
- 只用 `BLKPG` 或只重读、不写盘上表的做法不成立。
- btrfs 身份取 `BTRFS_IOC_FS_INFO` 的 FSID 与设备映射；映射缺失即拒绝。
- 支族：ext、xfs、btrfs 支持扩容；btrfs 另支持收缩；其余族在线一律拒绝。

LVM 链：

- 缩容前必须证明新末端之后没有已分配 extent；证明不出即拒绝。
- 不做 `pvmove`、不做 `lvreduce`；扩容链路按 `pvresize` 与文件系统扩容的组合执行。
- 参数与命令形态从 `src/cli.rs` 与 `src/lvm.rs` 取，T0 冻结。

## 7. 记录与恢复的可观察行为

- 记录只由本实现定义；不是本实现写下的记录：拒绝，不读后续帧，不改目标字节。
- 任意完整前缀必须能推出确定结论：可回滚、可重放、需人工。
- 回滚只回放表区原像，从末项到首项，逐条读回比对。
- 放弃回滚只把记录移入隔离区，目标字节不变。
- `records list` 列活跃与隔离条目并标注来源；`records verify` 校验单条；`records scan` 按容器目录枚举。

## 8. 基线的取数与比对

基线分两层。**全集由机器数出**：命令面与全部退出码构造点由 `plan/instruments/census.py` 从根目录源码解析，冻结在 `baseline/census.json` 与 `baseline/refusal-sites.tsv`；普查器不入 `rebuild/tests`。**期望值由旧版二进制给出**：需要环境才能观察的行为（盘面效果、退出码实跑、输出）不靠读源码，而是同一镜像、同一命令跑旧版二进制，由 `rebuild/tests/equivalence.rs` 比对新版与它，结果经 `plan/instruments/gate.py` 下结论（`06` §5 的 G7）。读源码得出的结论只用于写判据，不作为期望值。

1. 取数来源：命令声明与选项定义、退出码判定分支、输出结构体、文件系统能力表、工具调用参数、记录与恢复的状态转移。
2. 固定镜像配方：每类文件系统、每种表、每种目标形态各至少一个，生成脚本随代码交付；镜像本身不入库。
3. 比对器：对同一镜像跑两个二进制，比对退出码、stdout、stderr、JSON 与声明区间外摘要；差异必须落 `plan/divergences.md` 并带条目号。
4. 交付时把"必须运行才能确认"的项列入 `plan/05-静态自检.md` 的未执行清单，并写明命令。

## 9. 载体路径

基线包含一套"在虚拟机或其他隔离环境内执行同一命令"的载体（清单、协议、工作进程、远端、QEMU）。T0 从源码判定它是否具备完整可执行入口：

- 入口完整、依赖可达：纳入等价范围，按同一五项定义实现。
- 入口缺失或依赖不可得：不实现，登记为 D7，写明影响面（哪些命令在哪些场景下不可用）与恢复条件（载体可用时按同一架构补入）。
