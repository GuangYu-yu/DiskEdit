# 05 静态自检

交付前逐项填写。每行必须指到代码位置（文件与符号名）并说明靠什么机制成立；指不到的写「未执行」并补上要做什么。本表是人工审阅的入口，不替代运行。

状态词只有四个：**待执行**（已列入计划、尚未开始）、**未执行**（应做但没做或没跑）、**已通过**（实际核对过且无问题）、**未通过**（核对过且有问题）。「应该没问题」「未验证」「未复核」一律归入「未执行」，并写明补什么能验。
